# Deployment

The project uses Vite's standard static production build. Run `npm run build`; Vite writes the site to `dist/`. `npm run preview` serves that output locally for a production-like check.

GitHub Pages is the intended hosting platform, but deployment is not configured or verified. Before publishing, confirm the final repository name and whether the site is served from a repository subpath. Set Vite's `base` accordingly, then verify asset paths and the deployment workflow and repository Pages settings. No canonical URL or deployment URL is currently known.
